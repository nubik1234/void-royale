# Void Royale

Void Royale — королевская битва для Minecraft 1.20.1 на Forge. Игроки десантируются с C-130, собирают снаряжение на карте и сражаются, пока сужается безопасная зона.

Здесь публикуются готовые сборки мода и описания обновлений.

## Скачать

Откройте [последний релиз](https://github.com/nubik1234/void-royale/releases/latest) и скачайте файл `battleroyale-*.jar` из раздела **Assets**. Для игры нужны Minecraft 1.20.1, Java 17, Forge 47.3.0 и остальные моды из сборки сервера.

## Установка

1. Закройте Minecraft и откройте папку `mods` нужного профиля.
2. Уберите предыдущую версию BattleRoyale из `mods` и положите туда новый JAR.
3. Запустите Minecraft через Forge. Версия BattleRoyale должна совпадать с серверной.

Если Forge сообщает о несовместимости, сверьте версии с администратором сервера. В Void Royale 1.1.0 список обнаруженных несовпадений показывается на отдельном экране.
